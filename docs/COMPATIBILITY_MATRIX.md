# Compatibility Matrix

**Generated:** 2026-08-27
**Status:** Fase 0 — auditoría de compatibilidad, previa a cualquier instalación.

Este documento registra, para cada tecnología del stack, la versión seleccionada,
su estado de soporte oficial, los requisitos que impone, con qué se comprobó su
compatibilidad y el motivo de la elección. Dos elecciones **se desvían
deliberadamente** del baseline inicial del prompt (`docs/adr/009-version-deviations.md`
documenta el porqué): TypeScript (6.0.3 en vez de 7.x) y NestJS (11.2.3 en vez de 12.x).

## Fuentes consultadas

- Registro npm (`npm view <pkg> version|versions|dist-tags|peerDependencies|engines`), consultado en vivo el 2026-08-27.
- `https://endoflife.date/api/nodejs.json` para el calendario de soporte de Node.js.
- Documentación oficial de pnpm (`https://pnpm.io/installation`).
- `winget` como fuente de instaladores verificados para Windows (Node.js, nvm-windows).

## Checks adicionales realizados

- **Duplicación de versiones de React**: centralizada vía `pnpm catalog` (una sola entrada `react`/`react-dom` consumida por `portal-web`, `dashboard-web` y `packages/ui` como `peerDependency`).
- **ESM/CommonJS**: Next.js 16 y NestJS 11 conviven cada uno con su propia estrategia de módulos (Next usa ESM internamente vía su bundler; Nest 11 sigue en CommonJS por defecto) — no se fuerza `"type": "module"` a nivel de paquete compartido para evitar romper el build de Nest.
- **Dependencias deprecated**: no se detectó ninguna dependencia con aviso de deprecación en las consultas anteriores; se revisará de nuevo con `pnpm audit` al finalizar la Fase 1.
- **peerDependencies de `class-validator`/`class-transformer`** (requeridas indirectamente por `@nestjs/common`): `>=0.13.2` y `>=0.4.1` respectivamente — satisfechas por las versiones estables actuales (0.15.1 / 0.5.1).

## Pendiente de revalidar antes de cada instalación real

Turborepo, pnpm y npm registry cambian rápido. Antes de ejecutar `pnpm install` en cada fase se vuelve a correr `npm view <pkg> version` para los paquetes nuevos que se añadan, en vez de asumir que esta tabla sigue vigente indefinidamente.
